# 🌿 Apartment Home Server & Plant Tracker

Modular Home Server with Spaced-Repetition Chess Tactics and a mobile-first Plant Watering & Consumption Velocity Tracker.

[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/Tmimer/apartment)

## 🚀 1-Click Cloud Deployment

Click the button above or visit:
👉 **[Deploy to Render](https://render.com/deploy?repo=https://github.com/Tmimer/apartment)**

Render will automatically:
1. Provision a free PostgreSQL database (`plant-db`).
2. Wire up the `DATABASE_URL` environment variable.
3. Build and launch the Python FastAPI web server.
4. Auto-initialize the tables and starter plant data.

---

## 📱 Dedicated Mobile App (PWA)

Once deployed, open your live Render link on your phone (e.g. `https://apartment.onrender.com/plants`):
- **Android**: Tap the **📲 Install App** button in the header (or Chrome menu ⋮ $\rightarrow$ **Install app**).
- **iOS (iPhone)**: Tap Safari's **Share** button $\rightarrow$ **Add to Home Screen**.

The app runs in full-screen standalone mode with its own home screen icon, without needing your laptop to stay on.
